# Enterprise-Network-projects
Designed and implemented a secure enterprise LAN using Cisco Packet Tracer for a simulated organization with multiple departments.
------------------------------------------------------------------------------------------------------------------------------------------
*Technologies Used:* 
1. Cisco Packet Tracer 8.2.2
2. Cisco IOS CLI
3. VLANs
4. Router-on-a-Stick
5. DHCP
6. SSH
7. Port Security
8. Extended ACLs
9. 802.1Q Trunking

------------------------------------------------------------------------------------------------------------------------------------------
*Features*

✅ VLAN segmentation

✅ Inter-VLAN Routing

✅ DHCP

✅ SSH

✅ Port Security

✅ ACL Security

✅ Management VLAN
------------------------------------------------------------------------------------------------------------------------------------------
*IP Addressing*

| VLAN       | Network         |
| ---------- | --------------- |
| HR         | 192.168.10.0/24 |
| Finance    | 192.168.20.0/24 |
| IT         | 192.168.30.0/24 |
| Management | 192.168.99.0/24 |

------------------------------------------------------------------------------------------------------------------------------------------
*Security Implemented*

1. SSH only (Telnet disabled)
2. Local administrator authentication
3. Port Security
4. Sticky MAC
5. Disabled unused ports
6. ACL restricting HR access to Finance

------------------------------------------------------------------------------------------------------------------------------------------
*Skills Demonstrated*

1. Enterprise LAN Design
2. Network Segmentation
3. Router Configuration
4. Switch Configuration
5.Enterprise Security
6. Network Troubleshooting
